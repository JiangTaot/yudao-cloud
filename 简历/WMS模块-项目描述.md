# WMS 仓库管理系统 — 项目描述

## 版本一：精炼版（适合简历项目经历，80-120 字）

**项目名称**：基于 Spring Cloud 微服务架构的 SaaS 化仓储管理系统（WMS）

**项目描述**：
项目基于 Spring Boot 3.x + Spring Cloud 微服务架构，采用 MySQL + MyBatis Plus + Redis 技术栈，实现了入库、出库、移库、盘点四大核心单据流，以及库存余额管理、库存流水追踪、多租户数据隔离等核心能力。系统采用行级锁（SELECT FOR UPDATE）保证高并发下的库存一致性，通过 Feign 实现微服务间解耦调用，支持 Swagger 接口文档与 XXL-Job 定时任务调度。

**技术栈**：Spring Boot 3.x、Spring Cloud、MyBatis Plus、Redis、MySQL、Nacos、Feign、Spring Security、XXL-Job

**职责与成果**：
- 独立设计并实现四大库存单据（入库/出库/移库/盘点）的完整业务流程与状态机
- 设计库存变更引擎，利用数据库行锁 + 批量更新保证高并发下库存一致性
- 实现库存流水全链路追踪，支持从单据到库存变化的完整审计链
- 基于多租户方案实现 SaaS 化数据隔离，支持多货主/多仓库场景

## 版本二：详实版（适合详细项目介绍，200-300 字）

**项目名称**：Yudao WMS — SaaS 化仓库管理系统

**项目背景**：
作为 Yudao Cloud 企业级微服务平台的业务模块之一，从零构建了一套面向中小仓储企业的 SaaS 化仓库管理系统，覆盖仓库日常作业的核心单据流转与库存管控。

**技术架构**：
- **后端框架**：Spring Boot 3.x + Spring Cloud（Nacos 注册/配置中心）
- **数据层**：MySQL + MyBatis Plus + MyBatis Plus Join（连表插件）
- **缓存/锁**：Redis（Redisson），支持分布式锁与缓存加速
- **服务调用**：OpenFeign 实现微服务间 RPC 通信
- **安全**：Spring Security + Token 认证 + @PreAuthorize 细粒度权限控制
- **辅助组件**：Swagger/Knife4j 接口文档、XXL-Job 任务调度、FastExcel 报表导出、Easy-Trans 数据翻译

**核心功能**：
1. **基础资料管理**：仓库、货主/商户、物料（商品-SKU-品类-品牌）的 CRUD 及关联关系维护
2. **入库管理**：采购入库、退货入库、调拨入库等多类型入库，支持单据创建→审核→完成入库→库存自动增加
3. **出库管理**：销售出库、领料出库等，完成出库时自动校验库存充足性并扣减库存
4. **移库管理**：仓库间调拨，源仓出库 + 目标仓入库的库存双向变更
5. **盘点管理**：账面库存与实际库存核对，盈亏差异自动生成调整流水
6. **库存中心**：库存余额实时查询、库存流水全链路追踪（前后数量 + 金额 + 关联单据）
7. **统计看板**：多维度订单统计、库存趋势分析、商品/仓库库存排行

**技术亮点**：
- **库存并发安全**：采用 `SELECT FOR UPDATE` 行锁 + CAS（Compare And Swap）更新 + `DuplicateKeyException` 容错机制，确保高并发出入库场景下库存数据绝对一致
- **库存流水审计**：所有库存变动记录变更前/后数量与金额，关联单据类型与单号，实现完整的财务级审计追溯
- **批量防 N+1 查询**：Controller 层采用 Map 批量拼接模式，一次查询填充所有关联数据（商户、仓库、用户、SKU、物料），避免循环查询数据库
- **多租户 SaaS 架构**：基于 MyBatis Plus 拦截器实现 `tenant_id` 自动注入，数据行级隔离，支持多货主多仓库独立运营
- **标准模块化设计**：遵循 -api/-server 双模块拆分，api 层仅暴露 Feign 接口与 DTO，server 层独立部署，模块间零耦合
