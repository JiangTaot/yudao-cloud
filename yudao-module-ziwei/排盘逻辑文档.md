## 一、排盘流水线

`ZiweiChartServiceImpl.buildChartContext()` — 12步完整流程：

```
Step 1:  八字排盘 → 四柱（立春/节气分界，专业八字标准）
Step 2:  阴历转换 → 农历年月日（正月初一分界，紫微斗数标准）
Step 3:  命宫 + 身宫定位
Step 4:  十二宫排列 + 宫干（五虎遁）
Step 5:  五行局计算（纳音取数法）
Step 6:  安紫微星（商余迭代法）
Step 7:  安十四主星（紫微系6 + 天府系8）
Step 8:  安辅星（8颗）+ 杂曜（10颗）
Step 8b: 安扩展杂曜（20颗）+ 神煞（18颗）
Step 9:  填充全部70颗星曜到12宫位
Step 10: 四化（年干定）
Step 11: 大限
Step 12: 格局匹配
```

## 二、核心算法详解

### 2.1 四柱（八字）

**文件**: `BaziCalculator.java`
**关键区分**：

| | 四柱（八字） | 紫微斗数 |
|---|---|---|
| 年界 | 立春 | 正月初一 |
| 月界 | 节气 | — |
| 使用 | `getXxxExact()` | `lunar.yearTianGan()` |

**实现**：
```java
// 四柱 — 立春分界
yearPillar  = lunar.getYearGanExact() + lunar.getYearZhiExact()
monthPillar = lunar.getMonthGanExact() + lunar.getMonthZhiExact()
dayPillar   = lunar.getDayGanExact() + lunar.getDayZhiExact()
hourPillar  = lunar.getTimeGan() + lunar.getTimeZhi()

// 紫微斗数年干 — 正月初一分界
yearGan = TianGanEnum.ofName(lunar.yearTianGan())
yearZhi = DiZhiEnum.ofName(lunar.yearDiZhi())
```

### 2.2 命宫 / 身宫

**文件**: `MingGongCalculator.java`

```
命宫：寅宫起正月，顺数至生月（顺时针），逆数生时（逆时针）
     公式：absIdx = (lunarMonth + 1 - hourIndex + 12) % 12

身宫：寅宫起正月，顺数至生月（顺时针），顺数生时（顺时针）
     公式：absIdx = (lunarMonth + 1 + hourIndex) % 12
```

**晚子时处理**：23:00后出生，农历日+1 用于紫微星定位和日系星曜。

### 2.3 十二宫排列 + 宫干

**文件**: `PalaceSetupEngine.java`

- 从命宫开始，逆时针排列12宫
- 宫干用**五虎遁**：甲己→丙寅, 乙庚→戊寅, 丙辛→庚寅, 丁壬→壬寅, 戊癸→甲寅

### 2.4 五行局

**文件**: `WuxingJuCalculator.java`

纳音取数法：
```
天干取数：甲乙=1, 丙丁=2, 戊己=3, 庚辛=4, 壬癸=5
地支取数：子午丑未=1, 寅申卯酉=2, 辰戌巳亥=3
干支数相加，>5减5：
  1=木三局, 2=金四局, 3=水二局, 4=火六局, 5=土五局
```

---

### 2.5 安紫微星 / 天府星

**文件**: `ZiweiStarPlacer.java`, `TianfuStarPlacer.java`

**紫微星（商余迭代法）**：
```
1. 不断在日数上加 offset(从0递增)，直到(日+offset)能被局数整除
2. 商 = (日+offset)/局数, 商 %= 12, 紫微 = 商-1
3. offset偶 → 紫微 += offset（逆时针）
4. offset奇 → 紫微 -= offset（顺时针）
5. iztro索引(0=寅) → 绝对索引(0=子): abs = (iztro + 2) % 12
```

**天府星（轴对称）**：`abs = (16 - ziweiAbs) % 12`

**紫微系6星（逆时针）**：偏移 {0, 1, 3, 4, 5, 8}
**天府系8星（顺时针）**：偏移 {0, 1, 2, 3, 4, 5, 6, 10}

## 三、星曜亮度

**文件**: `BrightnessCalculator.java`

- 数据来源：文墨天机 QS（全书）体系
- 覆盖 **48 颗星** × 12 宫 = 576 亮度值
- 7级制：庙(1) > 旺(2) > 得(3) > 利(4) > 平(5) > 不(6) > 陷(7)
- 索引方式：文墨天机原生顺序（子=0, 丑=1, ...）
