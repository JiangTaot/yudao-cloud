# 紫微斗数排盘验证用例

## 验证方法

用以下出生时间在文墨天机 App 或 destiny.xfiles.com 排盘，对比本系统输出。

## 用例1：标准命盘

| 字段 | 值 |
|------|-----|
| 公历生日 | 1990-06-15 14:30 |
| 性别 | 男 |
| 地点 | 北京 |
| 预期八字 | 庚午 壬午 辛亥 乙未 |
| 预期命宫 | 寅（或相近地支） |
| 预期五行局 | 木三局（或按命宫天干地支查表） |

## 用例2：立春边界（年柱分界）

| 字段 | 值 |
|------|-----|
| 公历生日 | 2024-02-03 10:00 |
| 预期 | 年柱应属癸卯年（立春在2月4日） |

## 用例3：子时边界

| 字段 | 值 |
|------|-----|
| 公历生日 | 1990-06-15 23:30 |
| 预期 | 时柱应为次日干支（子时） |

## 用例4：闰月

| 字段 | 值 |
|------|-----|
| 公历生日 | 2023-05-19 12:00 |
| 预期 | 农历四月（闰二月后的四月） |

## 用例5：女性，逆行大限

| 字段 | 值 |
|------|-----|
| 公历生日 | 1990-06-15 14:30 |
| 性别 | 女 |
| 预期 | 大限应为逆行（逆时针） |
